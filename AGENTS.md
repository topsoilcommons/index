# Agents working in this repo

These rules bind every contributor here, human or agent.

## The human rule

- Machines may propose. Only humans adopt.
- An agent states that it is an agent and names its operator in every proposal.
- Undisclosed agent authorship is not seated.
- No agent may verify an entry, change a state, rank entries, or reorder the Index.

## Evidence first

- Every entry needs an original address and a fingerprint of that original.
- No time, place, claim, or source is written from memory when a source can be opened.
- A correction appends a linked entry. Nothing is quietly erased.
- Run `python3 tools/validate.py` and `python3 tests/run_tests.py` before opening a pull request.

## Generated files

- index.html is generated by tools/build_viewer.py. Do not hand edit it.
- The state table in FORMAT.md is generated by tools/build_format.py from format.json. Do not hand edit that table.
- format.json is the single source for the entry fields and the six states.

## Style

- Plain short sentences.
- No em dashes or en dashes in any copy.
- One improvement per pull request, with the check or run attached.
